# Правила запуска на CrazyGames (сводка для разработки)

Источник: docs.crazygames.com (requirements/*, sdk/*, resources/basic-launch-metrics), прочитано 2026-11-18.
Перед релизом перепроверить первоисточник — правила меняются (например, CTR-метрика появляется для запусков с 2026-11-23).

## 0. Как проходит запуск

- **Basic Launch** (первый этап): игра выходит без кастомизации под CrazyGames. SDK необязателен, **реклама и монетизация отключены**, внешняя реклама запрещена.
  - Тестируется 7–21 день. Заканчивается, когда игра онлайн ≥7 дней И набрала 500 игр; если 500 нет — автоматически через 21 день.
  - Метрики: средняя длина сессии (цель 10+ мин), удержание Day 1 (10–15%), конверсия «сыграл ≥1 мин» (80%+; загрузка <10 с, билд <20 МБ), CTR по обложке (топ-20% категории).
  - Обновлять игру можно в любой момент, апдейты авто-одобряются.
- **Full Launch**: после отбора по метрикам. Нужны SDK, gameplayStart/Stop, реклама только через SDK и т.д.
- В Developer Portal есть QA Tool — проверять игру им до отправки.
- Разработчики с повторными нарушениями получают ограничения на будущие отправки.

## 1. Технические требования

| Что | Лимит |
|---|---|
| Начальная загрузка | **≤ 50 МБ** (**≤ 20 МБ** для главной мобильной страницы) |
| Общий размер | ≤ 250 МБ (≤ 50 МБ если без SDK) |
| Количество файлов | ≤ 1500 |
| Время до геймплея (если файлы грузятся извне) | ≤ 20 с |

- Только **относительные пути**, абсолютные не загрузятся.
- Работать должно в **Chrome и Edge**; плохо работающие в Safari — отключаются там. На Chromebook с 4 ГБ RAM должно идти плавно.
- Ввод: мышь + клавиатура, плюс тач, если заявлена мобильная версия.
- Десктоп — ландшафт. Портрет допустим (чёрные полосы / фон).
- Определять устройство через SDK system info, **не** через `ontouchstart` / `maxTouchPoints`.
- Мобильные: в `body` добавить CSS `user-select: none` (+ префиксы `-webkit-`, `-moz-`, `-ms-`) — иначе лупа/контекстное меню. Игра должна работать в приложении CrazyGames (fullscreen, safe areas).
- iOS: если AudioContext приостановлен после возврата в приложение — `resume()` внутри жеста (`touchend`/`click`); одного `visibilitychange` недостаточно.
- На CrazyGames запускаются только **сжатые билды (Brotli или Gzip)**.
- Sitelock (если используем): внести в whitelist все домены `crazygames.com` и origin'ы iOS/Android приложений.
- Личные данные сверх событий SDK → уведомление Terms/Privacy для новых игроков (лучше простое уведомление, не блокирующий попап).
- Страницу ничего не должно скроллить: перехватывать `wheel` (non-passive + preventDefault), клавиши стрелок/пробела (`keydown` preventDefault), `contextmenu` вне канваса.

## 2. Геймплей и контент

- **Читаемость**: текст и картинки читаемы при `devicePixelRatio = 1`, в iframe 16:9 от 800×450 (мобильный) до 1920×1080.
- **Физика одинакова на любой частоте монитора** (60/144/165 Гц) → вся логика движения/пуль/коллизий в `_physics_process`, не в `_process`; никакой привязки к FPS.
- **Английский язык обязателен**; другие переводы — только качественные. Язык брать из `locale` SDK system info, fallback — English.
- Управление интуитивное на всех устройствах; раскладка клавиатуры: AZERTY-пользователям нужны ZQSD вместо WASD (по возможности использовать физические keycodes/переназначение).
- **Избегать клавиш с поведением браузера**: Escape выходит из fullscreen, Ctrl/Cmd+W закрывает вкладку → **не вешать паузу на Esc**.
- Плавность: быстрая загрузка, без ошибок и крашей.
- **Оригинальность**: название, ассеты, контент — свои. Не называть и не стилизовать как Tank Trouble и другие игры; без generic-названий; название и картинки соответствуют геймплею.
- **Fullscreen**: даёт платформа. **Собственные кнопки fullscreen запрещены.**
- **Без кросс-промо**: нельзя рекламировать другие игры/платформы. Разрешено (не как главный CTA в меню): ссылки на Discord/сайт разработчика (но не на браузерную версию игры), Steam/Epic для десктопных игр (только главное меню / конец демо), ссылка на CrazyGames, игры той же серии, Privacy/Terms. **Ссылки на App Store — никогда** (только метаданные в портале).
- **PEGI 12**: аудитория 13+; контент подходит для детей (танки/пули без крови и жестокости).
- **Full Launch: игрок попадает сразу в геймплей; если нельзя — максимум 1 клик.** Это влияет на главное меню (см. п. 6).

## 3. Реклама (только Full Launch, только через SDK)

- Форматы: midgame, rewarded, баннеры. Внешняя реклама запрещена.
- Реклама не должна прерывать игру, обманно срабатывать, идти цепочкой, и показываться до того, как игрок нормально поиграл.
- **Midgame**: не во время активной игры и не на кнопках навигации (меню, настройки, магазин). Подходит: переход между уровнями/раундами, после смерти. Игру ставить на паузу, UI блокировать до `adFinished`/`adError`. При `adError` игра продолжается как обычно. Звук глушить **только когда реклама реально началась** (`adStarted`), включать по окончании. Частоту SDK ограничивает сам (~3 мин; слишком ранний запрос → `adCooldown`).
- **Rewarded**: награда — «бонус», не необходимость (уровень нельзя проходить только через рекламу); не слишком часто, не цепочкой, кнопку не показывать во время игры; кнопка skip — того же размера/шрифта/цвета; понятно, что награда опциональна; есть альтернатива (например, за внутриигровую валюту); награда **только** на `adFinished`, никогда на `adError`. Нельзя midgame + rewarded «продолжить» между одними и теми же уровнями.
- **Баннеры**: только на экранах, где пользователь бывает ≥ ~5 с; никогда во время геймплея; не перекрывать UI; максимум 2 на экран.
- **AdBlock**: игра обязана работать. Нельзя блокировать/наказывать игроков с адблоком; можно отключить доп. фичи с пояснением (без попапов). Не оставлять кликабельными rewarded-кнопки, которые ничего не делают.
- Ошибки рекламы: `adsDisabled` (Basic Launch, Kids, оффлайн), `unfilled`, `adblock`, `adCooldown`, `other`.

## 4. SDK (Full Launch; в Basic достаточно gameplayStart)

- Инициализация асинхронная, как можно раньше (на экране загрузки). Для Godot у CrazyGames есть свой аддон, **но страница docs.crazygames.com/sdk/godot/intro сейчас 404** — у нас рукописная обёртка `addons/crazygames_sdk` (`CG`) + фасад `SDK`. Игровой код вызывает только `SDK.*`.
- `gameplayStart` — когда игра началась/возобновилась (старт, resume, revive, следующий уровень). Первый вызов задаёт базу для замера начального размера (пропускать нельзя).
- `gameplayStop` — на каждой паузе в игре: открыто меню, раунд/уровень закончен, пауза. После возобновления — снова `gameplayStart`. **Не** вызывать при потере фокуса — это делает платформа.
- `loadingStart/Stop` для Godot не нужны.
- `happytime` — только за настоящие достижения (рекорд), редко.
- `muteAudio` от SDK должен **перекрывать** внутриигровые настройки звука: тумблер «звук вкл» не должен включать то, что SDK заглушил.
- Модули Data/User применяются, если у игры есть сохранения/аккаунт (если есть вход — только аккаунт CrazyGames, внешние логины запрещены).
- Тестировать на `localhost` / `127.0.0.1` (реклама заменяется оверлеем).

## 5. Метаданные и обложки

- Описание игры и управление (текстом) — обязательны.
- Обложки без рамок, без текста кроме названия (никаких «New/Play»), без иконок и логотипов магазинов, без чужих визуалов, не размытые. Все три в едином стиле:
  - Ландшафт 16:9 — **1920×1080**
  - Портрет 2:3 — **800×1200**
  - Квадрат 1:1 — **800×800**
- Превью-видео: 15–20 с, ≤ 50 МБ, **без звука**, без ускорения, два варианта — 1080p 16:9 и 1080p 2:3; первый кадр = статичная обложка; без чёрных экранов/лого-заставок, чёрных полос, системного курсора, промо-текста, иконок соцсетей.

## 6. Рекомендации по качеству (Guideline, не обязательно)

- Онбординг прямо в геймплее, пропускаемый, больше визуала чем текста, показать управление (оверлей клавиатуры).
- Чёткие цели, быстрый отклик, единый арт-стиль, ровная громкость звука.
- **Одиночная игра должна быть так же заметна, как мультиплеер** (у нас PvP на одном устройстве + ИИ — режим против ИИ не прятать).
- Не менять жанр после отправки; регулярно обновлять; расширяемость контентом (уровни).

## 7. Что это значит для нашей танковой игры (чек-лист разработки)

1. **Физика/пули/движение** — только `_physics_process`, `delta`; проверить при 60 и 144 Гц.
2. **Пауза на Esc (решение заказчика, 2026-11-18) + P как запасная.** Риск: в браузерном fullscreen Esc выходит из полноэкранного режима и страница часто его не получает; пауза в fullscreen тогда работает через P. Не использовать Ctrl+W/F-клавиши в управлении.
3. **Клавиши**: WASD+Space и стрелки+Enter. Предусмотреть то, что пробел/стрелки скроллят страницу → перехват в HTML-шелле экспорта CrazyGames (через редактор/пресет, не вручную в `export_presets.cfg`).
4. **Главное меню**: Full Launch требует «сразу в геймплей или ≤1 клик» → меню делать минимальным: одна кнопка «Play» (или сразу раунд), режимы — внутри/после. Режим против ИИ виден наравне с PvP.
5. **Размер**: текстуры/аудио экономить — цель начальной загрузки **< 20 МБ** (мобильная главная и конверсия), жёсткий предел 50 МБ; файлов <1500; аудио — сжатое (ogg).
6. **Язык**: все строки на английском (через `tr()`/ключи, чтобы легко добавлять языки).
7. **Оригинальность**: своё название и арт, не клон-стилизация Tank Trouble; обложки без текста кроме названия.
8. **Контент PEGI 12**: без крови; взрывы мультяшные.
9. **Никаких собственных fullscreen-кнопок и ссылок на другие игры/магазины.**
10. **SDK**: `SDK.notify_gameplay_started()` при старте/возобновлении раунда, `notify_gameplay_stopped()` при меню/паузе/конце раунда (не на потере фокуса). Рекламу — только между раундами (после конца раунда), никогда на кнопках меню; `adError` → игра продолжается.
11. **Звук**: mute от SDK главнее настроек игрока (проверить в `SoundManager`).
12. **Мобильная версия (этап Бета)**: touch-управление, `user-select: none`, safe areas; для 2 игроков на одном экране — продумать раскладку.
13. **Сохранения**: если нужны — через SDK Data module / существующий `SaveManager` (localStorage на Web).
14. **Перед релизом**: прогнать QA Tool в Developer Portal; проверить Chrome + Edge (+Safari), Brotli/Gzip, относительные пути.

## 8. Решение по SDK (для комментария в задаче Notion)

- На **Basic Launch** SDK не обязателен и реклама отключена → для прототипа/демо достаточно `gameplayStart`.
- Для дохода нужен **Full Launch с SDK** (реклама только через SDK). Оставляем рукописную обёртку `addons/crazygames_sdk` + `SDK`-фасад: официальная страница Godot-аддона отдаёт 404.
- Ещё не проверено в живом браузере на домене crazygames.com — проверить при первом экспорте (задача «Экспорт в HTML5»).

## 9. Проверка билда (2026-11-18, прототип PvP)

Экспорт пресетом `CrazyGames` (`godot --headless --export-release "CrazyGames" Export/CrazyGames/index.html`), плагин `web_brotli_compressor` сжимает wasm/js/pck в `.br`.

| Что | Значение | Лимит CrazyGames |
|---|---|---|
| Всего без сжатия | ~40,2 МБ (`index.wasm` 38,6 МБ — движок) | ≤ 250 МБ; начальная ≤ 50 МБ |
| Всего с Brotli (`.br`) | ~7,2 МБ | мобильная главная ≤ 20 МБ |
| `index.pck` (игра) | 0,25 МБ (0,17 МБ в Brotli) | — |
| Файлов | 17 | ≤ 1500 |

- Сборка однопоточная (Emscripten, single-threaded) — COOP/COEP не нужны.
- Проверено в Chrome (через локальный сервер): игра грузится, `CrazyGames SDK.init()` resolved (`environment=local`), ввод с клавиатуры, стрельба, рендер работают.
- НЕ проверено: Edge/Safari, мобильные, реальный домен crazygames.com (QA Tool в Developer Portal), раздача `.br` с `Content-Encoding` на их стороне.
- Движок Godot (wasm ~38,6 МБ без сжатия) занимает почти весь размер: если CrazyGames считает начальную загрузку по несжатому размеру, мобильные 20 МБ не пройдут → уточнить в QA Tool; при необходимости сделать кастомный экспорт-шаблон без лишних модулей (3D, физика 3D и т.д.).
